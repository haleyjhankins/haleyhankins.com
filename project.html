Dynamic CMS Systems (DotCMS)

This landing page was built using DotCMS, a powerful content management system. It features a responsive design and integrates seamlessly with the Armstrong Air brand identity. I worked closely with the product owner to ensure that the backend was simple to update, and that the content could be managed efficiently by non-technical users.

Property of Lennox.

Technologies Used:

  • DotCMS w Velocity Scripting
  • HTML5 & CSS3
  • Tailwind
  • JavaScript
  • Responsive Web Principals
  • Wave Accessibility Tool (Browser Extension)
  • Lighthouse to measure performance (Browser Extension)
